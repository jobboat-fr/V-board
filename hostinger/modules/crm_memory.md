# CRM Memory Protocol

Maintain:
/data/.openclaw/workspace/crm/leads.md

Track:
- name
- company
- website
- source
- contact channel
- last interaction
- next follow-up
- opportunity value
- stage
- confidence
- risk
- notes

Rules:
- Do not invent contact details.
- Mark public evidence [EMP], inference [EST].
- Update CRM after lead scout, mail triage, or owner-approved outreach.
