# Document Vault Index Protocol

Maintain:
/data/.openclaw/workspace/docs_index/document_vault_index.md

Index every important document:
- filename
- category
- date if visible
- sensitivity: public/internal/confidential/highly confidential
- what it proves
- missing signature/date?
- owner/accountant/lawyer action needed
- related risk

Never expose confidential document contents to non-owner users.
